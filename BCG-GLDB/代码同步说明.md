# 代码同步说明

| 位置 | 原代码与论文的主要差异 | 本版处理 |
| --- | --- | --- |
| Patch-AE | 局部与全局两个等价的平均 L1 被描述为独立监督 | 单一整图平均 L1，等效系数 2.0，保留原目标数值尺度 |
| 生成模型 | 旧入口以 PET 端点组织训练，模型通道与分支配置不完全一致 | 以 PET 为 `z_0`、MRI 为 `z_T`；七处临床交互和 ZeroConv、多尺度 MRI、两层四头全局分支 |
| 扩散桥 | 旧损失含论文总式以外的辅助项 | 只采用 0.5×桥接残差损失 + 图像 L1 + Parc98 区域损失，保留随机反向转移 |
| 临床数据 | 静态表配合日期窗口会被当作全缺失；缺失字段可能影响生成网络 | 修复静态表读取；按观测掩码及可靠度限制双向交互 |
| 分类协议 | 单模型及分片测试评估与五模型同一测试集不一致 | 按受试者五折各训练一个模型，并在相同 96 例上评估 |
| MedicalNet | 旧新入口容易把随机初始化模型写作 Med3D 预训练模型 | 运行该对照须显式提供兼容的预训练权重；Baseline 直接复用同一实验 |

未修改论文、实验表格、原始研究数据或旧代码目录。新目录的 `vendor/` 是供新入口调用的旧源代码副本；其中仅修复了静态临床表日期查找问题。

尚未验证的是：原始 995 行最终分类清单、Med3D 权重、外部合成模型检查点、论文表值的完全复算及完整分辨率训练。这些输入未附在本地代码目录中；本版提供可执行入口和协议检查，不把单元测试结果等同于论文数值复现。
