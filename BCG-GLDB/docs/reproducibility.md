# 数据与复现边界

生成训练需要预处理并配对的MRI和FDG-PET、受试者级划分、25个临床字段与Parc98标签图。建议在本机的`data/`目录准备文件并编辑`configs/`；配置中的路径是占位示例。

分类实验还需诊断标签、受试者隔离的训练及固定测试划分，以及各PET来源对应的影像路径。MedicalNet50-3D预训练对照需单独获取兼容权重；外部生成方法的训练代码及检查点未包含在本仓库。

## 实现来源与版本差异

本仓库以本地`MRI2PET_论文对齐完整代码`为整理源。此前服务器端论文入口与本地版存在差异：已核查到桥损失权重为1而本地版为0.5，临床tokenizer和AE训练流程也有差异。因此不能宣称权重通用，也不能把服务器实验指标直接标注为本仓库的复现结果。

后续100% MRI端点直出、GV28损失及联合训练decoder等实验改变了训练目标和推理路径，不属于这里默认的论文桥残差训练入口。发布这些实验需要单独整理配置、版本及结果。

分类基线的部分细节、完整受试者清单与分折、外部生成模型权重及跨数据库实验仍需原始记录核实。代码测试不能代替论文结果复算或临床验证。
